# Run a quiet pattern break

Use the existing three-activity sample as an optional, self-paced break for adults. This is an entertainment prototype, not a cognitive assessment, treatment or learning-outcome claim. Participation and retries are optional; do not compare people by their performance.

## Prepare

Download the [standalone sample](https://github.com/CinEmin/recallkit/releases/download/v0.1.1-mit/recallkit-example.html) and open it locally before the session. It works offline and does not record scores or names. Keep the file available on the device you will use; the itch.io website itself requires a connection. On a shared screen, one volunteer operates the tiles while others suggest choices. Individual-device use requires a copy of the HTML on each device; there is no live multiplayer or synchronization.

## Facilitate three rounds

1. **Corners — pattern:** select **Show pattern**. Say: “Notice the highlighted squares. When you are ready, we will hide them and select those squares in any order.” Select **Hide & recall** only when the participant is ready. Allow another reveal and retry whenever wanted.
2. **Across the grid — sequence:** explain that the visible numbers indicate the selection order. Ask the participant to repeat that order after hiding. Advance with **Next level** after success.
3. **Think backwards — reverse:** explain the changed rule before revealing: repeat the numbered sequence backwards. This is a rule change, not a measure of ability. Finish with **Finish pack**; **Play again** restarts all three rounds.

There is no timer. Stop whenever the group wishes; completing every round is not required. For a visual or motor access barrier, offer verbal description, a volunteer operator or skipping the activity; this visually dependent prototype is not claimed to be universally accessible.

## Adapt the activity

Download [editable JSON](../samples/example.json) using GitHub's Download raw file control, then import it into the [offline editor](https://github.com/CinEmin/recallkit/releases/download/v0.1.1-mit/recallkit-editor.html). Change one level's tiles or mode, save JSON and check that the downloaded file exists. Export playable HTML and open that new file before sharing it. JSON is the editable source; HTML is the player. Importing replaces the current pack, so save existing work first. Follow the [authoring walkthrough](create-memory-activity.md) for detailed steps.

Optional discussion: “Which rule was clearest?” and “What would you change in your own activity?” Do not collect names or health information. If you voluntarily submit a public playtest report, describe whether you adapted and exported an activity and where you got stuck; do not include participant information. A facilitated session must not be reported as an unaided creator trial.
